### 判定
part1〜part4 はすべて WA（サンプルは通る。N≤9 のランダム500ケースで part1 は20件、part2 は35件、part3 は36件、part4 は20件が不一致）。part1 はさらに O(N²) で、N=3×10⁵ では約20秒かかり TLE。方針（同色の連続区間を使う）は正しいが、全 part に共通して「存在しない点まで距離を数える」バグがある。

### 添削
- part1: 各 i で右へ走査して O(N²)。区間末尾の1つ先が配列外でも有限値として扱う。反例 `8 / 1 2 1 2 1 1 1 1` → 正解 `1 1 1 1 1 2 3 4`、出力 `... 2 2 3`。
- part2: `D[i]` は左隣の異色までの距離だが、先頭区間では存在しない点まで数えている。`min(D[i], D[i+1])` は右の距離ではない。反例 `6 / 3 3 3 3 1 2` → 正解 `4 3 2 1 1 1`、出力 `4 2 3 1 1 1`。
- part3: 右 `E`・左 `F` を別々に求めて `min` を取る分解は正しい。ただし先頭区間の `F`・末尾区間の `E` が、存在しない点までの有限値のまま残る。同じ反例で `i=1` が 2 になる（正解 3）。`if (E[0])` は常に真で意味がない。
- part4: part3 を1本の配列 F にまとめた結果、右の情報が左に混ざる。反例は part1 と同じ。
- 「解説あり」は未完成（`d` を出力していない）。最後のループを次の形にすると完成する。

```diff
     for(int i=0;i<n;i++){
         int d=n;
-        if(L[i] !=0) d = min(d,i-L[i] +1);
+        if(L[i] != 0)   d = min(d, i - L[i] + 1);
+        if(R[i] != n-1) d = min(d, R[i] + 1 - i);
```

- `L(n,-1), R(n,n)` の初期値は不要（全要素を上書きする）。

**INF とは**
- 「その側に異色の点が存在しない」ことを表す、十分に大きな値（`1e9` など）。`min(左, 右)` を取るときに自然に無視される。
- 例: `3 3 3 3 1 2` の `i=1` は、右の異色までが 3、左には存在しない。part3 は存在しない左側に有限値 2 を入れて `min(2,3)=2` と誤答した。INF なら `min(INF,3)=3` で正しい。

**part3 の修正案（N≤9 のランダム1000ケースで愚直解と一致を確認）**
先頭区間では `F`（左）を INF、末尾区間では `E`（右）を INF として扱う。`firstLen`・`lastLen` は D を reverse する前に取る。

```cpp
const int INF = 1e9;
int firstLen = D[0], lastLen = D.back();  // reverse(D) の前に取得
// ... E, F を求める（既存のまま） ...
for (int i = 0; i < n; i++) {
    int e = (i >= n - lastLen) ? INF : E[i];  // 末尾区間: 右に異色なし
    int f = (i < firstLen)     ? INF : F[i];  // 先頭区間: 左に異色なし
    cout << min(e, f) << " \n"[i == n-1];
}
```

**INF の注意点**
- `INT_MAX` にすると `+1` で溢れるので、`1e9` 程度にする。
- `1e9` に N 回（最大 3×10⁵）足しても約 1.0003×10⁹ で、`int` の上限（約 2.1×10⁹）以内。この問題では溢れない。

### 解説
**着眼点**
- 答えは「左側で最も近い異色の点」と「右側で最も近い異色の点」の小さい方。左右は独立に求められる。
- 存在しない側は INF にする。2種類以上の色があるので、どちらか一方は必ず存在する。

**想定解（O(N)）**
左から1回、右から1回スキャンして `min` を取る。

```cpp
const int INF = 1e9;
vector<int> L(n, INF), R(n, INF);   // L[0], R[n-1] は INF のまま
for (int i = 1; i < n; i++)
    L[i] = (C[i] == C[i-1]) ? L[i-1] + 1 : 1;
for (int i = n-2; i >= 0; i--)
    R[i] = (C[i] == C[i+1]) ? R[i+1] + 1 : 1;
// 答え: min(L[i], R[i])
```

`L[0] = INF` から始めると、同色が続く間は INF（に +1 したもの）が引き継がれ、最初の異色の点で初めて 1 になる。先頭・末尾の区間を特別扱いする必要がない。

**本人の解法との比較**
- part3 の「左右に分解して min」が想定解の形。あとは存在しない側を INF にするだけで通る。
- 区間長を配列 D に圧縮して展開し直す部分は、隣と比べる漸化式に置き換えられる。
- part3 から part4 で左右を1本の配列にまとめたのが逆効果だった。行き詰まったら、まとめ直すより「存在しないときの値」を決める。

別解: 解説の `L[i]`/`R[i]`（区間の始点・終点）を持つ方法。
