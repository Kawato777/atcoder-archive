### 添削
指摘なし。
- 正当性: N=2 のときは入力が 1 個で、`A[0]=1` `A[1]=0` となり正しい。`A[j - 1]` の j は 1〜N の範囲なので範囲外アクセスもない。
- オーバーフロー: カウントは最大 N-1 で、`int` で足りる。
- 計算量: 入力 N-1 個を読んで N 個を出力するので O(N)。N の上限でも十分間に合う。
- 実装（任意）: `vector<int> A(n, 0)` の `0` は省略できる（`vector<int> A(n)` で 0 初期化される）。出力は `"\n"` を使っているので `endl` による遅延もない。

### 解説
- **着眼点**: 「各社員の直属の部下の数」は、自分を上司として指している人の数を数えるだけでよい。木構造を組み立てる必要はない。
- **想定解**: 上司の番号 A_i を読むたびに、その番号のカウンタを 1 増やす。最後に全員分を順に出力する。O(N)。
- **本人の解法との比較**: 想定解と同じ。これ以上簡単にはならない。
- 別解: 隣接リストに子を追加して `size()` を出す方法もあるが、人数だけが必要なのでカウント配列の方が簡潔。
