### 判定
answer key 版は正しい（O(N)）。first 版は `abcdefg` や `dreamxxxxx` で無限ループになる（どの分岐にも当たらず b が進まない）。second 版は途中のメモで判定になっていない。

### 添削
- first: `dream`/`erase` の分岐の外側に `else { NO; return }` が無い。最後に `else` を足すだけで無限ループは防げる。
- そもそも前から貪欲だと `dream`/`dreamer`、`erase`/`eraser` の先読み場合分けが必要で、バグりやすい。

### 解説
- 着眼点: 4語を反転すると、どの語も他の語の接頭辞にならない。反転した文字列を先頭から貪欲に取り除けば一意に決まる。
- 想定解: S と4語を反転し、先頭から一致する語を取り除く。O(N)。
- 本人の解法との比較: first は前から貪欲で場合分けが重い。answer key は向きを変えて曖昧さを消している。
- 別解: dp[i] = 先頭 i 文字が作れるか。4語を試して O(N)。
