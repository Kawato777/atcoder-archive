# タグの選び方

- 2〜4個。**既存タグを優先**し、表記ゆれを作らない（既存に `DP` があれば `動的計画法` は使わない）。
  既存タグは `./scripts/note --history` の `tags`、または `./scripts/note --info <パス>` の `tags`（使用回数順）で分かる
- 大分類と具体的な手法を両方入れると照合の精度が上がる（例: `DP, 桁DP`）
- 既存タグが少ない場合は下の語彙から選ぶ
- 既存タグが実態とずれている・語彙と表記ゆれしている（例: `Greedy` と `貪欲`）場合は、
  「過去ノートとの照合」の節に変更案として理由を一言添える（他のノートは編集しない）

## 語彙

| 分類 | タグ |
|---|---|
| 探索 | 全探索, bit全探索, 二分探索, BFS, DFS |
| 手法 | 貪欲, 累積和, いもす法, しゃくとり, ソート |
| DP | DP, 区間DP, bitDP, 桁DP |
| グラフ | グラフ, 木, ダイクストラ, Union-Find |
| 数学 | 整数論, 組み合わせ, 幾何 |
| データ構造 | データ構造, セグ木 |
| その他 | 文字列, シミュレーション, 実装, Ad-hoc |
